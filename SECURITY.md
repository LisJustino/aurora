# Segurança

## Relatar uma vulnerabilidade

Não publique vulnerabilidades, credenciais, tokens ou dados de usuários em uma
issue pública. Use o formulário privado de avisos de segurança do GitHub:

https://github.com/LisJustino/aurora/security/advisories/new

Inclua os passos mínimos para reproduzir o problema com dados fictícios e o
impacto observado. Não envie dados pessoais, financeiros ou de saúde.

## Escopo

O Aurora é uma aplicação web pública. Testes devem ser limitados a ambientes e
contas que você controla; não acesse dados de outras pessoas nem sistemas de
produção sem autorização explícita.
